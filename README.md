## 怎么用

```bash
scripts/new_week.sh 03          # 新建 W03 周记（自动填日期和主题）
$EDITOR log/W03.md              # 写「做了/卡住/下周」
# 把 status: 改成 done
python3 scripts/update_progress.py   # 刷新上面的进度表（或推送后由 CI 自动跑）
```

脚本零依赖（Python 3 标准库），幂等，可重复运行。

status 取值：`todo` / `wip` / `done` / `blocked` / `skip`

## 规则

1. **任何一周没有 git commit，那一周记 0 分**，下周必须先补。
2. 标 ⏸ 的是缓冲周，不是假期——没欠账就往下一阶段推进。
3. 数学/ML 走并行轨（每周 2h，从总时间里切，不加量），做项目卡在哪补哪。
4. 外链可能失效（原教程已过时），404 就搜替代品，别卡住。
